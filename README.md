# AdFission_Agent
AdFission Agent — An AIGC advertising creative fission engine. Turns one source asset into a testable matrix of strategy-tagged variants via multimodal deconstruction, LLM/SD dual-engine generation, and a QA decision loop. Two feedback loops (auto-rework + performance data) power a data flywheel that makes creatives smarter with every run.

## 📌 项目简介

**AdFission Agent（广告素材裂变 Agent）** 是一款面向投放团队与代理商创意团队的 AIGC 素材生产工具方向提案——输入一条原始素材，自动产出 N 个面向不同人群、渠道与卖点的可投放变体。

它解决的是一线投放里最真实的一个瓶颈：

- **素材有生命周期**：投放 3~7 天后因用户疲劳、审核与竞争环境变化进入衰退期，必须持续供给新版本做 A/B 测试；
- **多版本化依赖设计人力**：小团队无法支撑高频测试，代理商按客户项目交付时人力瓶颈更突出。

**核心价值**：把「1 条素材」变成「一个可测试的创意矩阵」，用可负担的成本与周期获得可规模化验证的好创意，让投放从「等素材」变为「选素材」。

**覆盖场景**：

- **平台自营**：优化师直接筛选、勾选、投放，追求测试速度与策略沉淀；
- **代理商代运营**：同时服务多品牌客户，素材按客户项目独立交付，需满足客户品牌基线约束与多客户数据隔离。

> 短期看，它是一个素材生成器；长期看，它是**与投放环境共同进化的增长引擎**。

### ① `index.html` —— 可交互 Demo

演示一条原始素材如何裂变为多版本新素材：

1. 打开页面后自动运行一次裂变（也可点击右上角「运行裂变」）；
2. 2 秒加载动画期间，顶栏流水线依次点亮：策略路由 → 文案重写 → 图像生成 → 质量评测；
3. 生成 6 张策略化素材卡片，每张带**策略标签 / 质量星级 / 创意简述 / 占位主视觉**；
4. 点击卡片 → 查看「创意说明」弹窗（含受众建议与质检建议）；
5. 卡片右上角圆圈 → 加入导出；顶栏下拉框 → 按策略筛选；
6. 「导出选中」→ Toast 提示已导出的素材数量（模拟）。

### ② `flow.html` —— Agent 运行流程图

自包含单文件，浏览器直接打开即可，顶栏「▶ 自动走查流程」可逐段高亮演示：

- 素材理解 → 创作生成 → 评测与调整 三段管线；
- 策略路由 + LLM / SD 双引擎并行创作；
- 质量评测决策节点（达标投放 / 不达标返工，最多 3 轮）；
- 底部双闭环回流带（自动返工闭环 + 经验回流闭环）。

## 🧠 核心逻辑：三段管线 + 双闭环

```
原始素材
   │  多模态解析（LLM + CV）
   ▼
🧠 ① 素材理解 ──► 创意 DNA 档案（视觉基线 · 核心卖点 · 人群画像 · CTA 模板）
   │  策略路由 · 6 路并行
   ▼
✨ ② 创作生成 ──► 策略路由 × (LLM 文案改写 ‖ SD 图生图/ControlNet) ──► N 个版本
   │  自动质检评分
   ▼
⚖️ ③ 评测与调整 ──► 菱形决策：是否达标？
        ├── ✔ 是 → 候选版本池 → 人工评审 → 导出投放 A/B
        └── ✖ 否 → 生成修正指令 → 携指令返回 ② 创作（≤ 3 轮）

闭环①  自动返工：不达标样本的修正指令 → 回流双引擎，定向重绘/改写
闭环②  经验回流：人工采用/弃用 + 投放效果数据 → 回流策略路由，更新权重
```

**六条创意策略方向**（每次运行按权重随机重组）：

| 策略 | 钩子 | 适用场景 |
|---|---|---|
| 🎧 突出功能 | 硬核参数 · 数据锚点 | 3C 数码垂类、测评内容 |
| 💰 突出价格 | 到手价对比 · 优惠力度 | 价格敏感人群、促销节点 |
| ✨ 突出颜值 | 外观设计 · 潮流质感 | 小红书图文、短视频种草 |
| 🏙️ 场景化 | 真实情境代入 | 通勤时段、本地生活流量 |
| 🎓 人群圈定 | 身份语境 + 权益门槛 | 校园流量、教育学习定向 |
| ⏰ 限时紧迫 | 倒计时 + 稀缺感 | 大促抢量、新品冷启动 |

## ✨ 核心能力

| 能力 | 说明 |
|---|---|
| **素材解构** | 解析原素材的构图、文案、核心卖点与人群设定，抽取可复用的「创意 DNA」，作为裂变的统一输入 |
| **策略生成** | 基于 6 条策略库做路由，在客户品牌基线约束下为每个版本匹配注意力钩子与受众画像，并生成独立「创意说明」 |
| **多路裂变** | 一次运行并行产出多个版本，保证「风格各异、根上同源」，不因批量处理而失真跑偏 |
| **局部重生成** | 对指定版本局部重绘（换背景 / 修正光影 / 替换人物）或局部改写文案，仅刷新该版本，无需整批重跑 |
| **多平台导出** | 内置信息流横/竖版、1:1 / 3:4 / 9:16、搜索、电商主图等规格；支持「图/视频 + 文案 + 投放建议 + 策略标签」按客户项目打包交付 |
| **质量筛选与反馈闭环** | 内置质检评分（星级 + 置信度）与投放建议；采用/驳回记录回流策略库，越用越懂业务 |

### 能力延伸：短视频裂变（规划）

- **现状范围**：图片素材裂变已可交付；短视频为二期规划，解决代理商「图片 + 短视频」双形态交付需求；
- **技术路径**：以「画面脚本 + 分镜描述」作为短视频的创意 DNA，LLM 负责脚本与分镜的多路裂变，文生视频 / 图生视频模型负责画面合成；与图片链路共用策略库与品牌基线护栏，产出片段 + 脚本 + 字幕版本，供创意人员剪辑成片；
- **配套验证**：视频维度的离线与在线指标纳入验证方案，保障从图片到视频的扩展不突破质量与品牌底线。

## 🔄 数据飞轮：越用越聪明的增长机制

Agent 的价值提升不来自基座模型本身，而来自运行方式：

> **投放 → 数据回流 → 策略优化 → 再投放**

- **投放**：素材进入真实流量接受检验；
- **数据回流**：CTR / CVR、消耗速度、优化师采纳与弃用信号被结构化采集；
- **策略优化**：策略库基于反馈调整路由权重、更新文案模板与视觉参数；
- **再投放**：带着新认知生成更贴合环境的素材版本。

**环境适配维度**：`行业 × 广告位 × 人群` 三维差异化，而非一套模板走天下。同一原始素材，在不同环境定向生长。

- **行业维度**——差异化卖点：快消重价格与场景冲动，3C 重参数与硬核功能，美妆重颜值与社交货币；
- **广告位维度**——差异化形态：信息流需 3 秒首屏拦截，搜索需卖点直给，电商详情页需信任背书与利益点前置；
- **人群维度**——差异化沟通：新客拉新讲痛点与身份认同，老客复购讲权益与升级。

**每周策略迭代**：高点击策略强化 ↑ / 低点击策略降权淘汰 / 策略种子库补位新假设 / 异常波动触发预警。

> 素材价值 = 生成能力 × 策略数据沉淀
> 生成能力趋于平稳，而策略数据只增不减——这就是**数据复利**，也是它区别于一次性批量工具的根本价值。

## 🆚 与现有批量工具的核心差异

现有批量工具的本质是「参数化复制」——批量替换文案、背景、尺寸与 Logo，产出同一套创意的机械重复，只能解决「量」的问题。

| 维度 | 批量工具 | AdFission Agent |
|---|---|---|
| 生产逻辑 | 按参数复制 | **按策略生产**：每个版本携带独立策略标签、创意说明与适配人群，拥有「测试价值」 |
| 内容一致性 | 批量处理后易跑偏 | 解构先行，**同源多变**：先理解卖点与视觉基线，再定向裂变，风格各异但根上同源 |
| 经验沉淀 | 只输出成品，不沉淀 | 质检评分 + 采用/驳回回流策略库，**越用越懂业务** |
| 交付流程 | 固定排版结果 | 支持**版本粒度局部精修 + 按平台/客户项目打包交付** |
| 交付物性质 | 一堆排版结果 | 一组**待验证的实验方案** |

> 批量工具回答「如何更快地做出更多一样的素材」，
> AdFission 回答「如何更聪明地做出更多值得测试、且能交付给客户的素材」。

## ✅ 验证机制（回答「值不值得投」）

验证分两步走——**离线守质量底线，在线守效果底线**。

**离线验证（受控数据集）**

| 维度 | 指标 | 通过标准 |
|---|---|---|
| 多样性 | 生成素材两两结构相似度 SSIM | 平均 SSIM **< 0.6** |
| 质量 | FID（与优质素材分布的距离） | **≤ 行业基准值** |
| 合规 | 违规内容拦截率 | **≥ 99%** |

**在线验证（A/B 测试）**

- 对照组：纯人工创作 ｜ 实验组：Agent 辅助创作
- 各 **100 组素材**，覆盖相同人群与版位，周期 **7 天**
- 核心指标：CTR / CVR / 消耗速度 / 素材采纳率
- 通过标准：**实验组 CTR / CVR 显著高于对照组（p < 0.05）**

**决策树**

| 离线 | 在线 | 结论 |
|---|---|---|
| ✅ | ✅ | **投入使用**，进入规模化生产 |
| ✅ | ❌ | **优化后使用**，优化策略生成层（路由权重、人群—策略匹配）后再复测 |
| ❌ | — | **暂不使用**，需更换基座模型或回炉重造 |

上线后仍有**持续监控**：CTR 衰退曲线追踪、月度策略复盘、数据飞轮滚动更新。

## ⚠️ 风险与边界

- **Agent 产出仅供候选，不替代创意终审**：生成物是「提案」而非「终稿」，投放与交付前须由人工完成终审——代理商创意人员做品牌与客户审美校验，客户做最终授权确认；涉及客户 logo、产品形象与核心主张时，最终把关必须落回人工；
- **责任边界**：Agent 承担创意放大与提效职能，**不承担**创意终审、品牌授权与合规责任，该边界需在交付协议中向客户明确，避免责任误判；
- **品牌一致性风险**：模型在重绘中可能漂移产品形态或 logo，需以「品牌基线约束 + 生成侧护栏 + 人工抽检」三道防线共同兜底。
